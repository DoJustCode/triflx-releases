# triflX — руководство

triflX сжимает картинки, GIF, видео, PDF и аудио на вашем Mac. Живёт в строке меню, работает в фоне, ничего не отправляет в интернет. Версия руководства: 2.2.

## 1. Установка и первый запуск
1. Скачайте `triflX.dmg` со страницы [Releases](../../../releases/latest), откройте и перетащите triflX в «Программы».
2. Приложение подписано и нотаризовано Apple: macOS 13 и новее, Apple Silicon и Intel.
3. При первом запуске появится приветствие с подсказками. В Dock значка нет — ищите иконку в строке меню.
4. Обновления приходят сами (Sparkle). Проверить вручную: меню → «Проверить обновления…».

Если кликнуть по иконке, откроется меню: статистика, действия с буфером, зоны, пресеты, паузa, резервные копии, настройки.

## 2. Как это работает
Для каждого файла triflX делает так:
1. Копирует оригинал в резервную папку (`~/Library/Application Support/triflX/Backups`).
2. Сжимает: результат записывается, **только если он меньше** (для преобразований — формат, масштаб, обрезка, конвертация — результат записывается всегда).
3. Показывает карточку результата с кнопкой «Вернуть оригинал».

Ваши файлы остаются на диске; ничего не загружается на серверы. Резервные копии удаляются через заданное число дней (по умолчанию 7).

## 3. Способы запустить сжатие
| Способ | Что происходит |
|---|---|
| **Буфер обмена** | Скриншот или картинка, скопированные в буфер, заменяются сжатой версией. Файлы, скопированные в Finder (⌘C), тоже. |
| **Папки** | Новые файлы в выбранных папках (по умолчанию Рабочий стол и Загрузки — включаются в настройках) сжимаются сами. |
| **Перетаскивание** | Бросьте файлы или папки на иконку в строке меню, в «Зону перетаскивания» или в окно настроек. ⌘ при отпускании — сильное сжатие. |
| **Меню Finder** | ПКМ → «Оптимизировать с triflX» (см. [раздел 13](#13-меню-finder)). Также служба «Оптимизировать в triflX» и «Открыть в программе». |
| **Горячие клавиши** | См. таблицу ниже. |
| **Быстрые команды** | Родные действия triflX ([раздел 14](#14-быстрые-команды-shortcuts)). |
| **Терминал / ИИ** | Команда `triflx` и MCP ([раздел 15](#15-терминал-и-ии-агенты)). |

Горячие клавиши (работают из любого приложения):

| Клавиши | Действие |
|---|---|
| ⌃⇧C | Оптимизировать буфер |
| ⌃⇧A | Сильное сжатие буфера |
| ⌃⇧− | Уменьшить картинку в буфере вдвое |
| ⌃⇧Z | Отменить последнюю оптимизацию (вернуть оригинал) |
| ⌃⇧= | Показать последний результат снова |
| ⌃O | Оптимизировать файлы, выделенные в Finder (при первом запуске macOS спросит разрешение «Автоматизация») |

## 4. Карточка результата
После сжатия в правом нижнем углу появляется карточка: миниатюра, размер «до → после», процент.
- **Нажмите на миниатюру** — откроется сравнение «до и после» (шторка для картинок, два кадра для видео и PDF). Миниатюру можно перетащить в любое приложение.
- **«Вернуть оригинал»** — кнопка видна сразу, восстанавливает файл из резервной копии.
- Значки действий: «Сравнить», «Пресеты», «Сильное сжатие», «Для мессенджера» (картинки до 1280 px, видео 720p до 16 МБ), «Уменьшить» (75/50/25%), «Конвертировать» (WebP, JPEG XL, JPEG, PNG, HEIC, AVIF), «Уложить в размер» (500 КБ / 1 / 2 / 5 МБ), «Обрезать» (16:9, 4:3, 3:2, 1:1, 9:16; для PDF — A4 и квадрат), для видео — «Убрать звук», «Скорость» (×0,5/1,5/2/4), «Сделать GIF». Дальше: «Копировать», «Открыть во внешнем редакторе», «Показать в Finder», «Поделиться», AirDrop, «Больше не следить за этой папкой».
- Все операции с карточки считаются **от оригинала**, а не от уже сжатого файла, поэтому качество не копится потерями.
- Карточка висит заданное время (по умолчанию 15 с) и **не скрывается, пока на ней курсор**. Показать последнюю снова — ⌃⇧=. Все недавние результаты — в меню → «Недавние результаты» (с возвратом оригинала позже).

## 5. Что поддерживается
| Тип | Форматы на входе | Как сжимается |
|---|---|---|
| Картинки | JPEG, PNG, HEIC, WebP, AVIF, JPEG XL, TIFF, BMP | Перекодирование с подбором качества, свой квантизатор PNG, WebP/JPEG XL/AVIF/HEIC на выходе, умная обрезка, лимит стороны и размера |
| GIF | GIF | Уменьшение кадров и палитры, опция ускорения |
| Видео | MP4, MOV, M4V, MPG, а также MKV, WebM, AVI, TS, FLV, WMV (через встроенный ffmpeg) | H.264 или HEVC, ограничение разрешения/fps/размера, без звука, скорость, MP4, GIF |
| PDF | PDF | Сжатие картинок внутри (стандартный фильтр macOS или заданный dpi), обрезка страниц |
| Аудио | WAV, AIFF, FLAC, MP3, а также OGG, Opus, WMA, APE (через ffmpeg) | AAC в M4A, стандартный или заданный битрейт |

Анимированные WebP/APNG и многокадровые файлы не сплющиваются до одного кадра. Битые, пустые и неподдерживаемые файлы пропускаются с понятным сообщением (подробности — в журнале ошибок).

## 6. Окно настроек: каждая вкладка
Меню → «Настройки…» (⌘,). Слева список вкладок и **поиск по настройкам**.

### Основное
- **Карточка результата и отмена.** *Показывать карточку*: 5 / 15 / 30 с или «Не скрывать». *Пауза перед сжатием файла из папки*: сразу, 2, 3 (по умолчанию), 5, 10 с — «окно отмены» (см. [раздел 12](#12-отмена-и-возврат-оригинала)).
- **Что оптимизировать.** Буфер обмена; данные TIFF (обычно из дизайн-редакторов — лучше не трогать); новые файлы в папках; пайплайны для буфера и для перетаскивания.
- **Качество.** *Максимальное сжатие / Сбалансированное / Высокое качество* (для JPEG-подобных форматов ≈ 0,5 / 0,7 / 0,85). *Макс. размер картинки* — потолок длинной стороны.
- **Файлы.** *Результат*: заменять файл (оригинал в копии) или сохранять рядом «имя.min.расширение». Окно результата, уведомления, автопроверка обновлений, запуск при входе. Блок «Недавнее» — последние сжатые файлы.

### Буфер
Что именно перехватывать: данные картинки (скриншоты, копирование из браузера), TIFF, файлы картинок / видео / аудио / PDF из Finder; «вместе с картинкой копировать путь к файлу». **Список приложений-исключений** — буфер из них не трогается; быстрее всего добавить через меню → «Игнорировать буфер из …». CorelDRAW, Illustrator, Figma, Sketch, Affinity и подобные распознаются сами: слои и вектор не портятся.

### Папки
Список наблюдаемых папок. Для каждой — свои правила: включена ли, *Результат* (как в общих / заменять / копия «.min»), *Качество*, *Макс. размер картинки*, *Пайплайн*, *Скриншоты* (не раскладывать / в папку «Скриншоты» / по месяцам / по дням), *Имя скриншота* по шаблону (`{date}`, `{time}`, `{name}`), кнопка **«Обработать существующие файлы…»**.
Как определяется «новый» файл: при запуске triflX запоминает, что уже лежит в папке; новым считается файл с новым именем или изменившимся содержимым. Дата файла не важна, поэтому `cp -p`, архивы и синхронизация работают. Файл сначала должен перестать расти (дописываться), потом идёт пауза-«окно отмены».

### Фото и видео
- *Фото → Метаданные*: удалять всё (мельче и приватнее) / сохранять всё / сохранять без геометок. Метаданные — это EXIF: камера, дата съёмки, объектив и место съёмки.
- *Видео → Сценарий*: **Универсальный** (1080p, H.264), **Для мессенджеров** (720p, до 16 МБ), **Запись экрана** (1080p, HEVC), **Максимальное качество** (оригинальное разрешение, HEVC), **Свои настройки** (разрешение, HEVC, лимит размера, всегда без звука). Разрешение только уменьшается.

### Фильтры
Применяются **только к автоматике** (буфер и папки); то, что вы перетащили сами, фильтры не затрагивают. Для каждого типа (картинки, видео, аудио, PDF): минимальный и максимальный размер, минимальное разрешение (картинки и видео), «пропускать, если за раз пришло больше N файлов», список расширений, которые не трогать. Значения по умолчанию: картинки от 5 КБ; видео от 200 КБ до 500 МБ, не больше 1 за раз, MKV и M4V не трогать; аудио до 100 МБ, не больше 2; PDF до 100 МБ, не больше 2.

### Дополнительно
- **Метка «уже оптимизировано»** — см. [раздел 11](#11-метка-уже-оптимизировано).
- **Пресеты**: лимит вложения для пресета «Почта» (1–100 МБ).
- **Фоновая обработка старых файлов** — [раздел 10](#10-существующие-файлы-и-фоновый-режим).
- **Адаптивное сжатие**: крупные фото сжимаются сильнее, мелкие мягче; тяжёлые страницы PDF получают меньше dpi. Ручной режим главнее.
- **Картинки**: умная обрезка (кадр смещается к главному объекту, Vision); сохранять широкий цвет (Display P3) вместо приведения к sRGB.
- **Видео**: ограничение частоты кадров (30 / 60 / половина / четверть исходной) — записи экрана 120 fps заметно уменьшаются.
- **Аудио**: битрейт AAC (стандартный macOS или заданный).
- **Зоны быстрых действий** — [раздел 8](#8-пайплайны-и-зоны-быстрых-действий).
- **Совместимость** (автоконвертация только в автоматике): *Картинки → JPEG* и *→ PNG* (AVIF, HEIC, WebP, JPEG XL, BMP, TIFF), *Видео → MP4* (MOV, MKV, WebM, AVI, FLV, WMV, TS, M4V, MPG…), *Аудио → M4A* (OGG, Opus, WMA, APE, MP3). Отметьте расширения, которые нужно превращать. WAV/AIFF/FLAC всегда становятся AAC.
- **PDF**: разрешение картинок внутри PDF (стандартное 144 dpi или 72–300 dpi).
- **Фото.app**: оптимизировать скопированные из «Фото» картинки; пропускать, если скопировано больше N; уменьшать длинную сторону до N px.
- **Имя файла из буфера**: шаблон с переменными `%y %m %d %H %M %S %i` (по умолчанию «Скриншот»).
- **Внешний редактор** для картинок / видео / аудио / PDF — на карточке появится кнопка «Открыть во внешнем редакторе».
- **Горячие клавиши** — справочная таблица.

### Хранение
Путь к рабочей папке, срок хранения резервных копий (1–90 дней), кнопки «Открыть рабочую папку», «Папка резервных копий», «Очистить рабочую папку» (не трогает файлы, на которые ещё ссылается буфер или недавние результаты). *Сохранять даты создания и изменения файла*; **«Приостановить автоматическую оптимизацию»** (то же — в меню).

### Пайплайны
Наборы шагов, применяемые за один проход: *Оптимизировать*, *Сильное сжатие*, *Уменьшить, %*, *Конвертировать в* (WebP, AVIF, JPEG XL, JPEG, PNG, HEIC), *Обрезать до пропорций*, *Убрать звук*, *Скорость видео*, *Видео в GIF*, *Сценарий видео*. Галочка **«Пресет»** выводит пайплайн в меню пресетов (см. [раздел 7](#7-пресеты-площадок)). Пайплайн можно назначить буферу, перетаскиванию, зоне или конкретной папке.

### Инструменты
- **Меню Finder** — переключатель и подсказка ([раздел 13](#13-меню-finder)).
- Справочник горячих клавиш; список игнорируемых приложений.
- **Установить команду triflx** и **Скопировать MCP-конфиг** ([раздел 15](#15-терминал-и-ии-агенты)).
- **Данные**: открыть папку резервных копий; **экспорт и импорт настроек** в файл.

## 7. Пресеты площадок
Один клик подгоняет файл под требования площадки. Доступны: значок «Пресеты» на карточке, меню → «Пресет для выделенного в Finder», окно пакета, действие Shortcuts «Применить пресет».

| Пресет | Картинки | Видео |
|---|---|---|
| Telegram | длинная сторона до 2560 px | 720p |
| Instagram — пост | обрезка 4:5, до 1350 px | 1080p, обрезка 4:5 |
| Instagram — сторис | обрезка 9:16, до 1920 px | 1080p, обрезка 9:16 |
| Веб | WebP, до 1920 px | 1080p H.264 |
| Почта | до 2048 px и не больше N МБ (по умолчанию 10, настраивается) | 720p, не больше N МБ |
| Slack / Discord | до 1920 px, не больше 8 МБ | 720p, не больше 8 МБ |

**Свои пресеты:** на вкладке «Пайплайны» создайте пайплайн и включите «Пресет» — он появится в тех же местах.

## 8. Пайплайны и зоны быстрых действий
**Зоны быстрых действий** (меню → «Зоны быстрых действий») — плавающая панель с плитками. Бросьте файлы на плитку — к ним применится её пайплайн (или «сильное сжатие»). Набор плиток настраивается во вкладке «Дополнительно». Отдельная «Зона перетаскивания» делает то же с обычными настройками.

## 9. Пакетная обработка
Если файлов больше пяти (или пакет уже идёт), открывается окно пакета:
1. **До старта** выберите: пресет или пайплайн, либо вручную — качество, формат картинок, масштаб, длинную сторону, метаданные, сильное сжатие.
2. **Идёт обработка:** общий прогресс и результат по каждому файлу. **Отменить** останавливает очередь, текущий файл откатывается к оригиналу.
3. **Итог:** сколько сэкономлено, список ошибок, кнопка **«Вернуть оригиналы»**.
Файлы, которые приходят во время работы, встают в очередь и обрабатываются следующим пакетом с теми же настройками.

## 10. Существующие файлы и фоновый режим
- **Вручную.** Вкладка «Папки» → у папки кнопка «Обработать существующие файлы…». Откроется список (с поиском по подпапкам, фильтрами возраста и «пропускать уже оптимизированные»), общий размер и кнопка **«Оценить экономию»** — реальная проверка на нескольких файлах каждого типа. Дальше — окно пакета.
- **В фоне** (Дополнительно → «Фоновая обработка старых файлов»): *только ночью (01:00–06:00)*, иначе — когда вы не за компьютером (5 минут без ввода); *старше N дней*; *пропускать файлы больше N МБ*; *не работать от батареи*. За один проход — до 25 файлов; помеченные пропускаются; оригиналы остаются в резервных копиях.

## 11. Метка «уже оптимизировано»
После сжатия (или если файл уже оптимален) triflX ставит на него расширенный атрибут `com.triflx.optimized` с размером, датой изменения и профилем качества. Автоматика (папки, буфер, фон) такие файлы пропускает. Если файл изменили — метка перестаёт действовать. **Ручные действия метку игнорируют.** Выключается в «Дополнительно». Посмотреть: `xattr -p com.triflx.optimized файл`, удалить: `xattr -d com.triflx.optimized файл`.

## 12. Отмена и возврат оригинала
- **До сжатия (файлы из папок):** на карточке с отсчётом «Сожму через N с» нажмите **«Отмена»** — файл остаётся как есть и помечается «не трогать». Длительность паузы — в «Основное» (0 = сразу).
- **Во время сжатия:** кнопка **«Отмена»** на карточке прерывает работу (в том числе экспорт видео и ffmpeg), временные файлы удаляются, оригинал не меняется, файл помечается «не трогать».
- **После сжатия:** **«Вернуть оригинал»** на карточке, ⌃⇧Z, или меню → «Недавние результаты». Возвращённый файл тоже помечается, чтобы автоматика не сжала его снова — удобно, если нужен «полный размер» для печати.
- Пауза всей автоматики: меню → «Приостановить автоматическую оптимизацию».

## 13. Меню Finder
Контекстное меню (правая кнопка) на файлах и папках: **«Оптимизировать с triflX»** — сжимает выделенное на месте (оригинал в резервной копии). Папки раскрываются, много файлов открывают окно пакета.
Это расширение Finder Sync. Включение: «Настройки → Инструменты → Меню Finder» (перезапускает Finder) либо «Системные настройки → Основные → Объекты входа и расширения → Расширения Finder → triflX». Если пункта нет — выключите и включите расширение, затем `killall Finder`.

## 14. Быстрые команды (Shortcuts)
В приложении «Быстрые команды» найдите triflX. Файлы приходят на вход и возвращаются на выход, **оригиналы не меняются**.
- **Optimize Files** — любые поддерживаемые файлы, сила сжатия на выбор
- **Compress Image** (качество, длинная сторона) · **Convert Image** (WebP, JPEG XL, AVIF, JPEG, PNG, HEIC) · **Resize Image** (%) · **Fit Image to File Size** · **Crop Image** (пропорции, умная обрезка)
- **Compress Video** (универсальный, мессенджеры, запись экрана, максимум) · **Video to GIF** · **Compress PDF**
- **Apply Preset** — пресет площадки к файлу
- **Optimize Clipboard**
Готовые фразы для Siri/Spotlight: «Optimize files with triflX», «Optimize clipboard with triflX», «Convert image with triflX».

## 15. Терминал и ИИ-агенты
Установка команды: «Настройки → Инструменты → Установить команду triflx» (создаёт ссылку `~/.local/bin/triflx`; если команда не находится, добавьте `~/.local/bin` в PATH). Либо вызывайте бинарник: `/Applications/triflX.app/Contents/MacOS/triflX`.

```bash
triflx optimize photo.png                    # заменить, оригинал в резервной копии
triflx optimize --convert webp --copy a.png  # сохранить рядом a.min.webp
triflx optimize --scale 50 --max-size 500KB photo.jpg
triflx optimize --video messenger movie.mov
triflx optimize --mp4 clip.mkv               # MKV/WebM/AVI → MP4
triflx optimize --json *.png                 # результат в JSON
```

| Параметр | Значение |
|---|---|
| `-a`, `--aggressive` | сильное сжатие |
| `--scale N` | уменьшить до N % |
| `--convert FMT` | webp, avif, jxl, jpeg, png, heic |
| `--crop W:H` | обрезка по центру (16:9, 1:1, 210:297) |
| `--max-size N` | уложить в размер: 500KB, 2MB (картинки) |
| `--mute` / `--speed X` / `--gif` / `--mp4` | видео: без звука / скорость / в GIF / в MP4 |
| `--metadata strip\|keep\|nogps` | EXIF и геометки |
| `--video universal\|messenger\|screen\|max`, `--video-limit MB` | сценарий и лимит видео |
| `--quality low\|medium\|high`, `--max-dim N` | качество и потолок стороны |
| `--copy` | не заменять, сохранить «имя.min.расширение» |
| `--json` | вывод в JSON |

**MCP для ИИ-агентов:** `triflx mcp` (stdio). Кнопка «Скопировать MCP-конфиг» в настройках кладёт готовый фрагмент в буфер. Инструмент: `optimize_file`.

## 16. Встроенный конвертер ffmpeg
Для форматов, которых нет в macOS (MKV, WebM, AVI, TS, FLV, WMV, OGG, Opus, WMA, APE), внутри приложения лежит отдельная программа ffmpeg 7.1.1 (`Contents/Helpers/ffmpeg`), собранная без GPL-компонентов (**LGPL v2.1+**), подписанная и нотаризованная вместе с приложением. Она запускается как отдельный процесс, переводит файл в MP4 (H.264 через VideoToolbox + AAC) или M4A, а дальше работает обычный конвейер. Исходники и параметры сборки: см. лицензионный файл внутри приложения (`THIRD-PARTY-NOTICES.txt`) и [ffmpeg.org](https://ffmpeg.org/releases/ffmpeg-7.1.1.tar.xz). Автоматически эти форматы конвертируются только если вы отметили их в «Совместимость». Конвертация — это смена формата, итоговый файл может быть больше исходного.

## 17. Где что хранится
| Что | Где |
|---|---|
| Резервные копии | `~/Library/Application Support/triflX/Backups` |
| Рабочая папка буфера | `~/Library/Application Support/triflX/Clipboard` (чистится сама) |

Журнал никуда не отправляется. «Сообщить о проблеме…» открывает форму на GitHub, журнал вы прикладываете сами.

## 18. Частые вопросы
**Файл не сжался — «Уже оптимально».** Результат не стал меньше, оригинал не тронут и помечен. Попробуйте «Сильное сжатие» на карточке.
**Сжалось слишком сильно / нужен полный размер.** «Вернуть оригинал» на карточке или ⌃⇧Z; поставьте паузу перед сжатием побольше; исключите папку или тип в «Фильтры».
**Скриншоты не сжимаются.** Проверьте «Следить за буфером» и что приложение не в списке исключений. Для папок — что папка включена и дописана.
**Пункт Finder не появился.** См. [раздел 13](#13-меню-finder).
**Видео MKV/WebM не обрабатывается автоматически.** Отметьте расширение в «Дополнительно → Совместимость → Видео → MP4».
**Как полностью приостановить?** Меню → «Приостановить автоматическую оптимизацию» или выключите «Следить за буфером» / «за папками».
**Конфиденциальность.** Всё происходит локально. Единственные сетевые запросы — проверка обновлений (Sparkle) и, если вы сами нажмёте, открытие страницы GitHub.

## 19. Версия 2.3: новые возможности
Все пункты настраиваются в окне настроек (боковая панель, поиск по ключевым словам находит каждую настройку). Интерфейс переведён на русский и английский.

### «Попробовать»
Окно сравнения одной картинки в нескольких вариантах рядом: качество 70/80/90, форматы WebP, AVIF, JPEG XL и исходный, режим «без потерь» для печати. У каждого варианта настоящий размер (файл кодируется целиком), экономия и шторка «до и после». Выберите вариант и нажмите «Применить». Открыть: кнопка «Попробовать» на карточке, меню triflX, Finder → triflX → «Попробовать варианты…», горячая клавиша ⌃⇧V, терминал `triflx try файл [--keep папка]`.

### Профили по источнику
Настройки → «Профили». Профиль выбирается по папке, приложению (буфер обмена), скриншотам, сайту-источнику файла (откуда скачан) или части имени. В профиле: формат, качество, масштаб, максимальная сторона, метаданные, лимит «уложить в N МБ», режим замены или копии, либо «не трогать». Работает для автоматической обработки: сверху вниз побеждает первый подходящий профиль; он главнее настроек папки, ручные действия не меняет. Профиль можно собрать на основе пайплайна.

### Уложить в размер
Одна цель, а параметры подбираются под тип: качество и масштаб (картинки), лесенка разрешений (видео), dpi (PDF). Если цель недостижима, получится самый маленький вариант, а на карточке и в терминале будет пометка «цель по размеру не достигнута». Файл, который уже меньше лимита, не трогается. Где: карточка («Уложить в размер»: 2, 5, 10, 25, 50 МБ или свой), пресеты «25 МБ (почта)», «10 МБ (Telegram)» и «свой лимит», «Быстрые команды» (Fit File to Size), терминал `--max-size 25MB`, пакетное окно.

### Статистика
Меню → «Статистика…» или Настройки → «Статистика»: всего, месяц, неделя, сегодня, число файлов, разбивка по типам, источникам и папкам, самые большие экономии. Данные хранятся только на Mac (`stats.jsonl`). Есть выключатель и кнопка «Сбросить статистику…». Сумма за неделю показана в меню. Терминал: `triflx stats [--json]`.

### Перетаскивание на значок и окно «на один раз»
Перетащите файлы на значок triflX в строке меню: откроется пакетное окно с настройками только для этого запуска (формат, размер, лимит, фон, водяной знак). Удерживайте ⌥ при отпускании, чтобы сжать сразу, ⌘ — сильное сжатие. Отключить окно: Основное → «Пропустить окно настроек при перетаскивании на значок». То же окно: меню → «Обработать файлы…».

### Горячие клавиши
Настройки → «Горячие клавиши»: нажмите на поле и введите сочетание (минимум один модификатор; Esc — отмена, ⌫ — выключить). Доступны: оптимизировать картинку из буфера, **выделенное в Finder**, сильное и среднее сжатие, вернуть оригинал, вернуть последнее, OCR (⌃⇧T), «Попробовать» (⌃⇧V). Для «выделенное в Finder» нужен доступ к управлению Finder: Системные настройки → Конфиденциальность и безопасность → Автоматизация → triflX → Finder. В настройках есть кнопка «Запросить / проверить», а при отсутствии доступа показывается подсказка. Меню Finder (правая кнопка) разрешения не требует.

### Оригиналы и откат по времени
Настройки → «Хранение»: «Не хранить» (≈30 минут для кнопки «Вернуть»), «Хранить N дней», «Хранить до лимита по размеру» (старые удаляются первыми). Копии младше двух минут не удаляются. Автоочистка при запуске и раз в 10 минут, показан занятый объём, есть «Очистить сейчас…». Окно **«История и оригиналы»** (меню): вернуть за 24 часа, 7 дней, всё или выборочно.

### Безопасный просмотр
Настройки → «Защита и просмотр». По умолчанию выключено. Перед заменой файла показывает «до и после» и спрашивает: **Заменить**, **Оставить оригинал** или **Сохранить копию «.min»**. Можно включить отдельно для автоматики и ручных действий, только для папок и типов. Выбор можно распространить на следующие файлы на 2 минуты.

### Защита от обработки
Настройки → «Защита и просмотр». По умолчанию защищены: `.git`, `.svn`, `.hg`, `node_modules`, `DerivedData`, `Pods`, проекты и рабочие области Xcode, библиотеки Фото и Lightroom, пакеты `.app`/`.framework`, кэши Photoshop и Adobe, системные папки, файлы iCloud, которые ещё не загружены, и резервные копии triflX. Списки имён, путей и типов редактируются, есть кнопки добавления папки и «Вернуть список по умолчанию». Автоматика (папки, буфер, фон) такие файлы пропускает. Ручные действия показывают предупреждение: «Пропустить защищённые» или «Всё равно обработать». Терминал отказывается без `--force`.

### Водяной знак
Настройки → «Водяной знак». По умолчанию выключено. Текст или картинка, положение (сетка 3×3), размер (% от ширины), непрозрачность, шрифт, цвет, тень, отступ; предпросмотр прямо в настройках. Отдельно включается для автоматики, пресетов и ручных действий, можно ограничить типами и папками. Терминал: `--watermark ТЕКСТ --wm-pos br --wm-opacity 0.5 --wm-size 25`, `--no-watermark`. Только для картинок. Не включайте знак для автоматики без метки «уже оптимизировано»: файл получил бы знак повторно.

### Документы
Настройки → «Документы». Меню triflX → «Документы», Finder → triflX → «Документы», «Быстрые команды», терминал `triflx convert`.
- **HEIC / RAW → JPEG или PNG**.
- **PDF → картинки**: формат PNG/JPEG/WebP, dpi, диапазон страниц (`1-3,5`), подпапка «имя pages». `triflx convert pdf2img --format png --dpi 150 --pages 1-3 файл.pdf`.
- **Картинки → один PDF**: порядок (имя, дата, как выбрано), размер страницы (по картинке, A4, Letter), поля в мм, сжатие. `triflx convert img2pdf --page a4 --order given -o out.pdf фото...`.
- **Склеить PDF**: `triflx convert merge -o out.pdf a.pdf b.pdf`.
- **Разбить PDF**: по одной странице, по N страниц или по диапазонам. `triflx convert split --every 2 файл.pdf`, `--ranges 1-3,4-6`.

Результат всегда лежит рядом с исходными файлами; оригиналы не меняются.

### Удаление фона и размер под шаблон
- **Удалить фон** (macOS 14 или новее; на macOS 13 пункты скрыты): Vision вырезает главный объект, результат — «имя-nobg.png» с прозрачностью (или белым/своим цветом фона, опция «обрезать по границам объекта»). Работает на устройстве. Карточка, меню, Finder, «Быстрые команды», терминал `triflx remove-bg файл`.
- **Размер под шаблон**: точный размер в пикселях для маркетплейсов и соцсетей. Встроенные: маркетплейс 1000×1000 и 900×1200, Instagram 1080×1350, квадрат 1080×1080, сторис 1080×1920, Open Graph 1200×630, превью видео 1280×720, шапка 1500×500, аватар 400×400. Режимы «Вписать» (поля цвета фона), «Заполнить» (обрезка по центру), «Умная обрезка» (кадр смещается к главному объекту). Свои шаблоны и «показывать в списке пресетов»: Настройки → «Размеры и фон». Терминал: `--template ig-post` или `--template 1080x1350:fit`.

### Распознавание текста (OCR)
Vision на устройстве, без интернета. Картинки и PDF (у PDF с текстовым слоем текст берётся из слоя, у сканов страницы распознаются). Результат: в буфер обмена, в `.txt` рядом или и то и другое; выбор языков (порядок важен), быстрый режим, опция «распознавать текст на скриншотах из буфера» (текст добавляется в буфер рядом с картинкой). Запуск: ⌃⇧T, меню triflX, Finder → triflX, «Быстрые команды» (Recognize Text), терминал `triflx ocr [--lang ru,en] [--txt] файл...`.

### Новые «Быстрые команды»
Fit File to Size, Resize to Template, Remove Background, Recognize Text, PDF to Images, Images to PDF, Merge PDFs.

### Меню Finder
Появился пункт «triflX…» с подменю: попробовать варианты, OCR, удалить фон, размер под шаблон, документы (PDF → картинки, картинки → PDF, склеить, разбить, HEIC/RAW → JPEG/PNG). Если подменю не появилось после обновления: `killall Finder`.

### Терминал: новое
`--template`, `--remove-bg`, `--lossless`, `--quality 1..100`, `--watermark`, `--force`, команды `ocr`, `remove-bg`, `try`, `stats`, `convert pdf2img|img2pdf|merge|split`, `selftest`. MCP-инструмент `optimize` получил `template`, `remove_background`, `lossless`, `force`.
